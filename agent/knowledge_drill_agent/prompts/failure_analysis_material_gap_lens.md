採点済み回答を、教材ギャップの観点だけで分析してください。

目的:
- 講座 Markdown の説明不足、曖昧さ、例の不足、順序の分かりにくさが、繰り返し誤答に関係しているかを見つける。
- 受講者の能力評価ではなく、教材改善につながる観測メモを書く。

制約:
- 講座 Markdown に存在しない社内ルール、方針、事実、義務を創作しないでください。
- 採点結果の missingPoints / failureTags / feedback に基づく観測だけを書いてください。
- 単発のミスより、複数回答にまたがる傾向を優先してください。
- 出力は日本語の短い分析メモにしてください。JSON の最終 schema はここでは返さないでください。

必ず含める観点:
- 繰り返し不足している理解
- 関連する講座セクション
- 教材側の改善余地
- 根拠となる採点結果の要約
