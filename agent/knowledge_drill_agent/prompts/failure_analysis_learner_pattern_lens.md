採点済み回答を、受講者のつまずきパターンの観点だけで分析してください。

目的:
- 複数の回答に共通して現れる missingPoints、failureTags、部分正答、混同を抽出する。
- 受講者の理解不足と、資料側の説明不足の可能性を分けて整理する。

制約:
- 孤立したミスより、繰り返し発生しているパターンを優先してください。
- 必要な evidence であり、かつ入力で提供済みの場合を除き、受講者回答の原文を含めないでください。
- 受講者を責めないでください。
- 出力は日本語の短い分析メモにしてください。JSON の最終 schema はここでは返さないでください。

必ず含める観点:
- 共通する missingPoints / failureTags
- affectedCount: その誤答傾向を示した受講者数
- sampleSize: 提供された採点済み回答の受講者総数
- likelyCause の候補
- targetSections の候補

人数の扱い:
- 分母は常に全回答者数です。該当者だけを分母にした「3名中3名」「100%」のような表現は使わないでください。
- 人数比の表示は最終出力の affectedCount / sampleSize に任せ、分析メモでは該当 learner と missingPoints / failureTags を中心に書いてください。
