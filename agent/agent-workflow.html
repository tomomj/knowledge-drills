Knowledge Drills — Agent Workflow

backend が task ごとに ADK の leaf agent を直接実行する（root_agent への転送はしない）

全体フロー

Frontend教材・回答・分析
→
Backend API検証と Firestore 保存
→task_name
+ JSON
ADK Runnertask ごとに 1 Agent
→
GeminiJSON で応答

応答はスキーマ検証してから backend が保存・反映する（失敗時は retry）

4つのタスクと担当 Agent

generate_drill drill_generator_agent 教材から実務シナリオ型ドリルを3問つくる
grade_answer grading_agent rubric に沿って回答を採点しフィードバックする
analyze_failures failure_analysis_agent 誤答の傾向から Failure Signal を抽出する ↓詳細
propose_document_patch document_patch_agent 弱点を補う最小限の教材修正案をつくる

failure_analysis_agent の中身（3ステージ）

1. 並列分析 — 3つの視点で同時に分析
受講者の誤解つまずきパターン
教材のギャップ説明不足・曖昧さ
設問の品質誤答を誘発していないか
▼
2. レビューループ — 3回くり返して所見を絞り込む
evidence_critic根拠の強さで採用・棄却
→
critic_reviewer判断を独立レビュー
⟳ ×3
▼
3. 最終化
finalizer承認された所見だけを整形
→
FailureAnalysisOutputfailureSignals として backend へ

ソース: agent/knowledge_drill_agent/agent.py ／ ADK の SequentialAgent → ParallelAgent + LoopAgent(max_iterations=3) 構成。 環境変数 KNOWLEDGE_DRILL_AGENT_ANALYSIS_MODE=single で単一 Agent モードに切替可。
