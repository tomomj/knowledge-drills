# Requirements Document

## Project Description (Input)
初回ログイン時のデモ講座シードと講座一覧の改善ループ表示。審査員(新規ユーザー)がログインした
直後の講座一覧が空で、プロダクトの価値(改善ループ)を体験する導線がない問題を解決する。

1. backend: 初回アクセス時(ユーザーの講座が 0 件)に、そのユーザー所有のデモ講座 2 つを
   Firestore へ自動投入する。
   - ①「DevOps × AI Agent Hackathon 2026 参加ガイド(デモ)」= v1 + 生成済みドリル +
     採点済み回答 4 件(「回答を分析する」が即押せる状態。分析自体は実 agent が実行する)。
     教材はハッカソン概要を独自に要約した Markdown とし、審査員が内容を熟知しているため
     設問・採点・パッチ提案の妥当性を自分の知識で検証できる。教材には意図的な記載不足
     (例: 提出要件の例外条件)を 1 箇所仕込み、分析が教材ギャップを特定できるようにする。
     公式ページの文章は転載せず、独自の要約・言い換えで作成する
   - ②「経費精算の判断基準(デモ・改善 3 周済み)」= v3 + 更新履歴(diff 付き) +
     バージョン別の scored run 3 件(スコア推移カードと更新履歴が最初から見える)。
     エンジニアリング以外の教材にも汎用であることを示す
   - すべて固定データで agent 呼び出しなし、投入は冪等、デモ講座は通常の講座として削除可能
2. frontend: 講座一覧の各行にスコアのミニスパークライン(scored run 2 件以上の講座のみ)と
   デモ表記を追加し、「今すぐ分析を試せます」等の状態バッジと初回案内バナーで最初の一歩を
   誘導する。

合意済み HTML モック(動画ショット別モック Shot 1)あり。
