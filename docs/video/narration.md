## TTS 入力(誤読対策込み)

表示文言との差分のみ:

- 「腐っていく」→「くさっていく」、「また腐ります」→「またくさります」、「腐りはじめます」→「くさりはじめます」
- 「DevOps」→「デブオプス」
- 「Knowledge Drills」→「ナレッジドリルズ」

生成コマンド例:

```bash
./tts-gemini.sh "書いた瞬間から、くさっていくドキュメントに、デブオプスを。" 00-title.wav Charon
```
